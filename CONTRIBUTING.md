# Contributing to Enola CLI

Enola CLI is **source-visible proprietary software** ([LICENSE](LICENSE)). The source code is public so you can read, audit and compile it for personal use — but it is not an open-source project.

## Code contributions

**Code contributions are not accepted.** Pull requests containing code will be closed. The license does not permit derivative works, and the project does not operate a contributor license agreement.

## What IS welcome

- **🐛 Bug reports** — open an issue using the [bug report form](https://github.com/SalvadorPalmaRodriguez/enola-cli-lite/issues/new/choose). Please include version, OS, exact command and output.
- **💡 Feature suggestions** — open an issue describing the use case, or write to salvadorpalmarodriguez@gmail.com.
- **📚 Documentation feedback** — typos, unclear explanations or outdated examples: open an issue.
- **🔐 Security reports** — **email only**, never public issues. See [SECURITY.md](SECURITY.md). Reporting within 72 hours of discovery is required by the license (§5).

## Questions

Check the docs first:

- Online: https://salvadorpalmarodriguez.github.io/enola-cli-lite/
- Offline: `enola-cli docs faq` / `enola-cli docs search <term>`
